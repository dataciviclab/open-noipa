# Fonti dati

## NoiPA Open Data

- **Portale**: https://dati-noipa.mef.gov.it/cl/web/open-data/dataset
- **Endpoint SPARQL**: https://sparql-noipa.mef.gov.it/sparql (GET only, XML)
- **Gestore**: MEF/RGS via SOGEI S.p.A.
- **License**: CC-BY-4.0

## Accesso dati

CSV aggregati disponibili via portale Liferay. Ogni entry type ha un CSV
per mese con colonne specifiche già pulite e aggregate.

## Range temporale

- Personale: gen 2019 — oggi (~80 mesi)
- Pensioni: gen 2017 — oggi (endpoint separato, non incluso)
